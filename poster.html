Project Objective

The goal is to bridge the gap between abstract physics and visual software. By simulating the N-body problem and Kepler's Laws, this project provides a technical sandbox for educators and students to analyze orbital behavior without the distraction of gamification.

Current MVP Features

Keplerian Logic

Mathematical calculation of elliptical planetary paths based on semi-major axes and eccentricity.

2D Engine

High-performance Vector2 physics engine implementation optimized for libGDX rendering cycles.

Euler Integration

Real-time numerical updates for position and velocity using a standard time-step approach.

Time Scaling

Interactive control of simulation speed, allowing for precise observational analysis of fast orbits.

Future Roadmap

  • Runge-Kutta (RK4)

    Replacing Euler with 4th-order integration to eliminate numerical drift.

  • Adams-Bashforth

    Multi-step prediction for enhanced efficiency at high velocities.

  • 3D Vector Refactor

    Upgrade to Vector3 to model orbital inclination and axial tilt.

  • JPL Horizons Integration

    Fetching real NASA ephemerides for verifiable scientific conditions.

  • PPN Method

    Post-Newtonian testing for relativistic gravitational verification.
